# Polyglot Multi-Language Repository

This repository contains 5 modular folders showcasing a polyglot architecture covering **JSX, TSX, Kotlin, Rust, Java, Python, JavaScript, and TypeScript**.

## Folder Structure & Language Distribution

Each folder contains between 4 files (well within the ≤ 7–8 files limit):

### 1. `frontend-components/` (4 files)
- `UserProfile.jsx` - React JSX functional component
- `Dashboard.tsx` - React TSX TypeScript component with interfaces
- `theme.js` - JavaScript UI theme definitions
- `types.ts` - TypeScript shared type declarations

### 2. `backend-api/` (4 files)
- `UserService.java` - Java user management service
- `OrderController.kt` - Kotlin order controller and data model
- `config.js` - JavaScript server runtime configuration
- `client.ts` - TypeScript API HTTP client class

### 3. `systems-core/` (4 files)
- `engine.rs` - Rust high-performance compute engine implementation
- `main.rs` - Rust application entry point
- `bridge.ts` - TypeScript native interface bindings
- `NativeBridge.kt` - Kotlin JNI interop bridge

### 4. `data-pipeline/` (4 files)
- `processor.py` - Python data cleaning and batch processing
- `aggregator.py` - Python statistical aggregation functions
- `ChartWidget.jsx` - React JSX data visualization component
- `MetricsCard.tsx` - React TSX metric display card

### 5. `shared-services/` (4 files)
- `DataRepository.java` - Java generic thread-safe repository
- `NotificationHandler.kt` - Kotlin notification dispatcher
- `helpers.js` - JavaScript utility functions
- `script_runner.py` - Python subprocess automation runner
